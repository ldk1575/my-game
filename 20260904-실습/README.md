## 실행

```bash
node server.js
```

→ http://localhost:3100

**설치할 게 없다.** `npm install`도 필요 없다 — 의존성 0개다.

> 노드 문서는 `better-sqlite3`를 예로 들었고 트러블슈팅 1번이 그 빌드 에러(`node-gyp`)였다.
> 그건 네이티브 모듈이라 빌드 도구(맥 Xcode CLT / 윈도우 빌드 툴·Python)가 필요하다.
> 이 앱은 **Node 22부터 런타임에 내장된 `node:sqlite`** 를 쓴다. 설치도 빌드도 없어 그 함정을 통째로 건너뛴다.
> (확인: `node -v` 가 v22 이상이면 된다. 이 PC는 v24.19.0)

## 창구(엔드포인트)

통째로 열려 있지 않고 정해진 것만 연다. 창구 = **주소(URL) + 동사**.

| 동사 | 주소 | 하는 일 | CRUD |
|---|---|---|---|
| GET | `/api/todos?filter=all\|today` | 목록 보기 | Read |
| POST | `/api/todos` | 할 일 추가 | Create |
| PATCH | `/api/todos/:id/toggle` | 완료 토글 | Update |
| DELETE | `/api/todos/:id` | 삭제 | Delete |
| GET | `/api/tags` | 태그 목록 | Read |

## 오늘 배운 것이 코드 어디에 있나

| 배운 것 | 어디에 | 무엇을 했나 |
|---|---|---|
| **표로 나누고 관계로 잇기** | `db.js` 스키마 | `todos` · `tags` · `todo_tags` 세 표 |
| **N:M은 연결 표로** | `todo_tags` | 할 일↔태그가 양쪽 다 여럿 → 연결 표를 사이에 둔 두 개의 1:N |
| **정규화** | `tags` | 태그 이름을 할 일마다 안 적고 한 번만 두고 번호로 가리킴 |
| **파라미터화 쿼리** | `db.js` 전체 | 모든 쿼리가 `?` 자리표. 문자열 이어 붙이기 **없음** |
| **트랜잭션** | `addTodo()` | 할 일+태그+연결 = 쓰기 여러 번 → `BEGIN`/`COMMIT`/`ROLLBACK` |
| **색인** | `idx_todos_due` 외 2개 | "오늘 마감만" / "이 할 일의 태그" 같은 **실제 화면의 질문**에 맞춰 최소한만 |
| **경쟁에 강한 쓰기** | `toggle` 쿼리 | 앱에서 읽어와 계산하지 않고 `SET is_done = 1 - is_done` 으로 DB에서 뒤집음 |
| **제약으로 막기** | `tags.name UNIQUE` | 같은 태그가 두 번 생기지 않게 DB가 막는다 |
| **연쇄 삭제** | `ON DELETE CASCADE` | 할 일을 지우면 연결 줄만 함께 지워지고 태그 행은 남는다 |

## 다음 — 길 B (Supabase)

같은 앱을 클라우드 Postgres로 옮기면 남에게 링크로 보여줄 수 있다. 바꿀 것:

1. `db.js` 를 Supabase 클라이언트로 교체

3. **RLS(행 수준 보안) 켜기** — 안 켜면 공개 키로 누구나 데이터에 접근한다
4. 무료 티어 함정 확인 — 1주 미사용 시 일시정지 / 자동 백업 없음 / DB 500MB
