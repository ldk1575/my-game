# 내 Todo 앱 — 길 B v2 (PWA · 앱 UI)

AI에이전트 2기 · 2026-09-04 노드「데이터베이스」실습

v1과 **같은 백엔드**를 쓰면서, 화면을 **앱처럼** 바꾸고 **홈 화면에 추가**할 수 있게 만든 버전.

| | [v1](../cloud/) | **v2 (여기)** |
|---|---|---|
| 화면 | 웹페이지 형태 | **앱 형태** — 상단 바 고정, 하단 `+` 버튼, 올라오는 입력창 |
| 홈 화면 추가 | 안 됨 | **됨** (아이콘·전체화면) |
| 오프라인 | 안 뜸 | **껍데기는 뜸** (Service Worker) |
| 백엔드 | ← **완전히 동일** (표·RLS·`add_todo` 함수 모두 공용) |

> **백엔드 설정은 [`../cloud/supabase-setup.sql`](../cloud/supabase-setup.sql) 하나뿐입니다.**
> v1에서 이미 실행했다면 v2를 위해 다시 할 일이 없습니다.
> 공격 테스트도 [`../cloud/verify-rls.mjs`](../cloud/verify-rls.mjs) 를 그대로 씁니다.

## 실행

**배포된 링크**

```
https://ldk1575.github.io/my-game/20260904-실습/cloud-v2/
```

**배포 전 로컬 확인**

```bash
node serve.mjs
```
→ http://localhost:3200

`file://` 로 열면 안 됩니다. CDN에서 ESM을 못 가져오고, **Service Worker는 보안
컨텍스트(https 또는 localhost)에서만 등록**됩니다.

## 홈 화면에 추가하기

**안드로이드(Chrome)** — 링크를 열면 상단에 `홈 화면에 추가` 버튼이 뜹니다.
또는 `⋮` → **앱 설치** / **홈 화면에 추가**.

**iOS(Safari)** — 공유 버튼 → **홈 화면에 추가**.
iOS는 **Chrome이 아니라 Safari로 열어야** 추가됩니다.

추가하면 아이콘이 생기고, **주소창 없이 전체화면**으로 열립니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 + 익명 로그인 + Supabase 호출 |
| `manifest.webmanifest` | 앱 이름·아이콘·`display:standalone` |
| `sw.js` | Service Worker — 앱 껍데기 캐시 |
| `make-icons.py` | 아이콘 생성 (`python make-icons.py`, Pillow 필요) |
| `icon-192/512/maskable`, `apple-touch-icon`, `favicon-64` | 아이콘 |
| `vendor/supabase.js` | **supabase-js 라이브러리(208KB)** — CDN 대신 여기서 불러온다 |
| `serve.mjs` | 로컬 확인용 정적 서버 |

## 무엇을 넣었나

| 요소 | 왜 |
|---|---|
| `manifest.webmanifest` | 홈 화면 추가와 전체화면 실행의 조건 |
| **maskable 아이콘** | 안드로이드가 원·사각 등 임의 모양으로 잘라내므로, 그림을 가운데 안쪽에만 뒀다 |
| `sw.js` | 껍데기 7개 파일(라이브러리 포함)을 캐시 → 연결이 느리거나 없어도 앱이 **바로** 뜬다 |
| `viewport-fit=cover` + `env(safe-area-inset-*)` | 아이폰 노치·홈바에 내용이 가리지 않게 |
| `beforeinstallprompt` | 헤더의 `홈 화면에 추가` 버튼 — 설치법을 사용자가 찾지 않아도 되게 |
| `display-mode: standalone` 감지 | 홈 화면에서 실행 중이면 설명 배너를 숨긴다 |

## 앱 UI로 바꾼 것

- **상단 바 고정** — 스크롤해도 제목과 `전체`/`오늘` 탭이 남는다
- **오른쪽 아래 `+` 버튼** — 엄지가 닿는 자리
- **아래에서 올라오는 입력창** — 배경이 어두워지고 시트가 슬라이드로 올라온다
- **마감일 빠른 선택** — `오늘` `내일` `다음 주` `없음`
- **터치 영역 44px** — 보이는 크기는 유지하고 `::before` 로 넓힘

## 오프라인은 어디까지 되나

**껍데기까지**입니다. 연결이 없어도 앱은 뜨고 `오프라인입니다` 배너가 표시되며,
연결되면 목록을 다시 불러옵니다.

**할 일 데이터는 캐시하지 않습니다** — Supabase에 있고 최신이어야 하니까요.
`sw.js` 에서 다른 출처(Supabase) 요청은 **아예 캐시에서 제외**했습니다.
남의 토큰이 섞이거나 옛 데이터가 보이면 안 되기 때문입니다.

> 연결 없이도 **추가**까지 되게 하려면 로컬 큐 + 나중에 동기화 + 충돌 해소가 필요합니다.
> 그건 오늘 범위를 넘습니다.

### 오프라인 판정을 이벤트로 바꾼 이유

처음엔 `navigator.onLine` 을 봤는데, 그 값은 **'네트워크 인터페이스가 있는지'만**
알려줍니다. 와이파이에 붙어 있고 인터넷은 안 되는 상황을 못 잡습니다.
그래서 ① `online`/`offline` **이벤트를 직접 신뢰**하고 ② 요청이 실제로 실패하면
그때도 오프라인으로 표시합니다.

## ⚠️ 파일을 고치면 `sw.js` 의 캐시 버전을 올려야 합니다

```js
const CACHE = 'todo-shell-v4';   // ← 이 숫자
```

안 올리면 사용자에게 **옛 화면이 계속 나옵니다.** Service Worker가 캐시를 먼저 주기 때문입니다.
