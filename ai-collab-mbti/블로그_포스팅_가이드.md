# 블로그스팟 포스팅 가이드

`index.html`을 GitHub Pages에 올린 뒤, 블로그 포스트에는 그것을 불러오는 `iframe` 한 줄만 넣습니다.

> ⚠️ **포스트 본문에 `index.html` 전체를 붙여넣지 마세요.**
> 본문에 `<style>`이 들어가면 그 CSS가 **블로그 페이지 전체에** 적용됩니다.
> `body{background:...}`, `button{...}`, `h1{...}` 같은 전역 선택자가 있어서
> 블로그 배경이 검게 바뀌고 다른 글의 버튼·제목까지 함께 변합니다.
> 또 `<!doctype html>`·`<html>`·`<head>`는 포스트 본문에 들어갈 수 없어 블로거가 지우거나 뒤엉킵니다.
> `iframe`으로 넣으면 테스트의 CSS가 완전히 격리됩니다.

## 1. 글 설정에 넣을 값

### 제목

```
나는 AI를 어떻게 쓰는 사람일까? 20문항으로 알아보는 나의 AI 협업 성향 (16유형)
```

*대안 두 개*
- `AI 협업 성향 테스트 — 나는 드라이버형일까, 네비게이터형일까? (20문항)`
- `클로드 코드로 일해 본 사람이라면 공감할 20문항 — 나의 AI 협업 성향 테스트`

### 퍼머링크 (맞춤 설정)

```
ai-collaboration-mbti-test
```

기존 글(`financial-mbti-test`)과 같은 규칙입니다. 영문·숫자·하이픈만 씁니다.

### 검색 설명

```
AI와 함께 일하는 방식은 사람마다 다릅니다. 직접 손대는 드라이버형과 지시하고 판단하는 네비게이터형, 명세를 먼저 쓰는 사람과 만들면서 정하는 사람. 20문항으로 4가지 축을 나눠 16가지 AI 협업 유형 중 내 타입을 찾아보세요.
```

블로거 검색 설명은 150자 안팎이 안전합니다. 길면 뒤가 잘립니다.

### 라벨

```

```

## 1-2. 썸네일 이미지

`thumbnail.png` (1200×630) 을 함께 만들어 두었습니다.

**블로거는 본문의 첫 번째 이미지를 썸네일로 씁니다.** 그래서 이미지를 **글 맨 위**에 넣어야 합니다.

1. 편집기를 **작성** 모드(HTML 보기가 아닌)로 바꿉니다
2. 커서를 글 맨 위에 두고 툴바의 **이미지 아이콘** → **컴퓨터에서 업로드** → `thumbnail.png` 선택
3. 다시 **HTML 보기**로 바꾸면 맨 위에 `<div class="separator">…<img …></div>` 가 생겨 있습니다
4. 그 아래에 본문(3번 항목)을 붙여넣습니다

이렇게 하면 블로그 목록과 카카오톡·페이스북 공유 미리보기에 이 이미지가 뜹니다.

> 문구를 고치고 싶으면 `thumbnail.html` 을 수정한 뒤 다시 캡처하면 됩니다.
> `1200×630` 은 소셜 공유 미리보기의 표준 크기입니다.

## 3. 발행 순서

1. ~~GitHub에 올리고 Pages 켜기~~ → **완료**. 주소는 `https://ldk1575.github.io/my-game/ai-collab-mbti/`
2. 블로거 포스트에서 **먼저 기존에 붙여넣은 코드를 전체 삭제**합니다 (`index.html` 전체를 붙인 상태라면 반드시)
3. **HTML 보기** 상태로 위 본문을 붙여넣기 — 주소는 이미 채워져 있습니다
4. 제목 · 퍼머링크 · 검색 설명 · 라벨 입력
5. **미리보기**로 확인 — 테스트가 뜨는지, **블로그 배경·버튼 스타일이 안 깨졌는지**
6. 게시
7. 발행된 주소를 `README.md`의 "블로그 포스팅" 칸에 채우고 다시 커밋

## 4. 왜 본문 글이 필요한가

`iframe` 하나만 넣으면 검색 엔진이 읽을 글이 거의 없습니다. `iframe` 안의 내용은 **다른 페이지의 것**이라 이 글의 내용으로 잡히지 않습니다.

그래서 위 본문에는 도입 문단, 네 축 설명, 유형 예시를 **텍스트로** 넣었습니다. 검색 노출과 방문자 이해를 함께 챙기는 부분입니다.

---

## 5. 높이가 안 맞으면

`iframe`의 `height="820"`은 고정값입니다. 결과 화면이 길어 안쪽에 스크롤이 생길 수 있습니다.

- 간단한 해결 — `height`를 900~1000으로 올려 봅니다
- 정확한 해결 — 테스트 페이지가 자기 높이를 블로그에 알려주게 만듭니다(`postMessage`). 필요하면 추가할 수 있습니다
