# 숫자 맞추기 게임 (Number Guessing Game)

컴퓨터가 정한 1~100 사이의 숫자를 UP / DOWN 힌트를 보고 맞추는 웹 게임입니다.

브라우저만 있으면 실행됩니다. 설치도, 서버도 필요 없습니다.

---

## 게임 규칙

1. 게임이 시작되면 컴퓨터가 **1부터 100 사이의 숫자 하나**를 무작위로 정합니다. 이 숫자는 화면에 보이지 않습니다.
2. 입력창에 숫자를 적고 **확인** 버튼을 누릅니다. (엔터 키로도 됩니다)
3. 입력한 숫자와 정답을 비교해서 힌트가 나옵니다.
4. 맞출 때까지 2~3번을 반복합니다. 시도할 때마다 **시도 횟수**가 1씩 올라갑니다.
5. 정답을 맞추면 성공 메시지와 함께 몇 번 만에 맞췄는지 보여줍니다.
6. **다시 하기**를 누르면 새 숫자로 게임이 다시 시작됩니다.

### 힌트 읽는 법

| 힌트 | 색 | 뜻 | 다음에 할 일 |
|---|---|---|---|
| **UP** | 주황 | 입력한 숫자가 정답보다 **작다** | 더 **큰** 숫자를 입력 |
| **DOWN** | 파랑 | 입력한 숫자가 정답보다 **크다** | 더 **작은** 숫자를 입력 |
| **정답!** | 초록 | 숫자를 맞췄다 | 다시 하기로 새 게임 시작 |

### 잘못된 입력

아래의 경우에는 빨간 경고 메시지가 뜨고, **시도 횟수는 올라가지 않습니다.**

- 아무것도 입력하지 않고 확인을 누른 경우
- 1보다 작거나 100보다 큰 숫자를 입력한 경우
- 3.5 같은 소수를 입력한 경우

---

## 잘 맞추는 요령

가운데부터 찍고 힌트에 따라 범위를 절반씩 줄이면 **최대 7번 안에** 반드시 맞출 수 있습니다.

```
50 입력 → UP    (정답은 51~100)
75 입력 → DOWN  (정답은 51~74)
62 입력 → UP    (정답은 63~74)
68 입력 → UP    (정답은 69~74)
71 입력 → DOWN  (정답은 69~70)
69 입력 → 정답!  (6번 만에 성공)
```

## 화면 구성

```
┌─────────────────────────────┐
│      숫자 맞추기 게임         │
│   1~100 사이의 숫자를 맞춰보세요! │
│                              │
│   [ 숫자 입력      ] [확인]   │
│                              │
│            UP                │
│      50 보다 큰 숫자예요.      │
│                              │
│  시도 횟수: 1번   최고 기록: 6번 │
│                              │
│        [ 다시 하기 ]          │
└─────────────────────────────┘
```

| 요소 | 설명 |
|---|---|
| 숫자 입력 | 1~100 사이의 정수를 입력하는 칸 |
| 확인 | 입력한 숫자를 정답과 비교 (엔터 키로 대체 가능) |
| 힌트 영역 | UP / DOWN / 정답 / 경고 메시지가 표시되는 곳 |
| 시도 횟수 | 이번 판에서 확인을 누른 횟수 |
| 최고 기록 | 지금까지 가장 적은 시도 횟수로 맞춘 기록 |
| 다시 하기 | 새 숫자로 게임을 다시 시작 |

## 기능

- 게임 시작 및 재시작 시 1~100 사이 정수 무작위 생성
- UP / DOWN 힌트 표시
- 시도 횟수 카운트
- 정답 시 성공 메시지와 시도 횟수 표시
- 다시 하기로 게임 초기화
- 입력값 검증 (빈값 / 정수 여부 / 범위)
- 엔터 키로 확인
- 최고 기록 저장 (브라우저에 저장되어 새로고침해도 유지)
- 힌트별 색상 구분과 애니메이션

## 실행 방법

**방법 1 — 파일 열기**

`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행됩니다.

**방법 2 — GitHub Pages**

저장소의 Settings → Pages 에서 Source를 `main / (root)` 로 설정하면 아래 주소로 접속할 수 있습니다.

```
https://ldk1575.github.io/my-game/number-guessing-game/
```

## 기술

| 항목 | 내용 |
|---|---|
| 구성 | `index.html` 단일 파일 (HTML + CSS + JavaScript) |
| 외부 라이브러리 | 없음 |
| 백엔드 | 없음 |
| 저장소 | 최고 기록만 브라우저 `localStorage` 에 저장 |

브라우저가 `localStorage` 를 막아둔 경우(시크릿 모드 등)에도 최고 기록만 표시되지 않을 뿐, 게임은 정상적으로 동작합니다.
